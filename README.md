========================================
   电商勒索短信智能识别系统
   面向电商场景的勒索短信智能识别系统
========================================

一、项目简介

本系统基于BERT预训练语言模型和软标签训练策略，实现电商场景下勒索短信的智能识别。
系统能够自动区分正常短信、广告短信和勒索短信三类文本，并提供关键词高亮、遮挡实验、
注意力可视化等多角度可解释性分析功能。

主要特点：
- 勒索短信召回率100%，不漏判
- 支持文字输入和截图OCR识别
- 提供8个功能标签页的交互式界面
- 支持批量短信检测


二、运行环境要求

- 操作系统：Windows 10/11 或 Linux
- Python 版本：3.8 或更高
- 硬件要求：建议 8GB 以上内存，CPU可运行（有GPU更佳）


三、安装步骤

1. 解压项目压缩包到任意目录（建议路径不含中文）

2. 打开命令行终端，进入项目目录：
   cd 你的项目路径

3. 创建虚拟环境（推荐）：
   python -m venv .venv

4. 激活虚拟环境：
   Windows: .venv\Scripts\activate
   Linux/Mac: source .venv/bin/activate

5. 安装依赖包：
   pip install -r requirements.txt

   如果下载速度慢，可使用清华镜像：
   pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple


四、运行系统

激活虚拟环境后，执行以下命令：

   python app_new4.py

启动成功后，终端会显示：
   Running on local URL:  http://127.0.0.1:7860

打开浏览器，访问上述地址即可使用系统。


五、功能说明

系统包含8个功能标签页：

| 标签页 | 功能说明 |
|--------|----------|
| 文本分析 | 输入短信，系统自动识别并返回分类结果和关键词高亮 |
| 截图识别 | 上传聊天截图，OCR自动提取文字并逐句分析 |
| 遮挡分析 | 自动/手动遮挡关键词，量化其对模型决策的影响 |
| 鲁棒性测试 | 生成8种文本变体，测试模型的语义理解能力 |
| 可解释性 | 梯度贡献度可视化，展示模型对每个词的关注程度 |
| 性能概览 | 展示模型在8条精选样本上的测试结果 |
| 数据与创新 | 数据集统计和创新点总结 |
| 批量检测 | 每行一条短信，同时分析多条 |

七、常见问题

Q1: 启动时提示“ModuleNotFoundError: No module named 'xxx'”
A1: 请确保已执行 pip install -r requirements.txt 安装所有依赖

Q2: 首次使用截图识别功能时较慢
A2: EasyOCR首次运行会自动下载模型文件（约50MB），请耐心等待

Q3: 模型加载失败
A3: 请检查 model_ransom_detection 文件夹是否存在且包含完整模型文件

Q4: 端口7860被占用
A4: 修改 app_new4.py 最后一行，将 server_port=7860 改为其他端口号
